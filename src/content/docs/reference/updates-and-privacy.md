## How update checks work

Once a day, when its window opens, XONOVA asks GitHub for the list of releases on
[github.com/Antik79/xonova-releases](https://github.com/Antik79/xonova-releases). When a newer version is
out, **“x.y.z available”** appears under the logo. Click it to open the release page and download it
yourself.

- **Beta versions** are only offered to people already running a beta.
- **Nothing is downloaded or installed automatically.** You stay in control of when you update.

## What's sent

The request carries **no personal data**. GitHub sees your IP address (as with any web request) and the
name `XONOVA-update-check`. Nothing else is sent: no usage data, no presets, no system details.

## Switching it off, or checking now

**gear → Updates**:

- **Check automatically (once a day)** – untick to stop the daily check.
- **Check now** – check immediately.

## Updating

Install the new version over the old one exactly as in [Installation](/xonova-docs/getting-started/installation/).
Your presets, wavetables and settings are kept, and your projects keep their sounds and automation:
parameter ids never change between versions.
