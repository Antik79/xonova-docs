On macOS, use <kbd>Cmd</kbd> wherever <kbd>Ctrl</kbd> is listed.

## Keyboard

| Keys | Does |
|---|---|
| <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> <kbd>F</kbd> <kbd>G</kbd> <kbd>H</kbd> <kbd>J</kbd> <kbd>K</kbd> <kbd>L</kbd> <kbd>;</kbd> | Play white keys |
| <kbd>W</kbd> <kbd>E</kbd> <kbd>T</kbd> <kbd>Y</kbd> <kbd>U</kbd> <kbd>O</kbd> <kbd>P</kbd> | Play black keys |
| <kbd>Z</kbd> / <kbd>X</kbd> | Typing keys an octave down / up |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> or <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redo |
| Arrow keys | Step the focused control |
| <kbd>Escape</kbd> | Cancel MIDI learn |

**In the preset browser**

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Jump to the search |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Audition the previous / next preset |
| <kbd>Enter</kbd> | Load and close |
| <kbd>Escape</kbd> | Clear the search; press again to close |

## Mouse

| Gesture | On | Does |
|---|---|---|
| Drag | Knob, slider, value | Change the value |
| <kbd>Ctrl</kbd>-drag | Knob, slider, value | Fine steps |
| Wheel | Knob, slider, value | Step the value |
| Double-click | Knob, slider, value, routing handle | Reset to default |
| Middle-click | Knob, slider, value | Type a value |
| Right-click | Knob, slider | Enter value, modulation options, MIDI learn |
| Drag a tab, macro handle or chip onto a knob | Modulation panel, macros | Create a modulation routing |
| <kbd>Alt</kbd>-drag | Modulated knob | Change the routing depth |
| Double-click | Macro label | Rename the macro |
| Click / drag | Step sequencer | Draw steps |
| Double-click | Step | Reset the step to the middle |
| Click / drag / <kbd>Alt</kbd>-drag | Custom LFO display | Add and move points / bend segments |
| Double-click or right-click | Point on a custom LFO | Remove it |
| Drag | Envelope display handles | Attack, decay/sustain, release |
| Click | Lower part of a key | Play louder |
| Drag | Window corner | Resize |
